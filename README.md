# 🚀 Apex Web Studio

> Landing page e site institucional de alta performance para conversão de clientes, desenvolvido com foco em design moderno, estética tecnológica (neon/dark) e otimização para SEO e dispositivos móveis.

---

## 🌐 Demonstração
* **Domínio:** [apexwebdigital.com.br](https://apexwebdigital.com.br)
* **Status do Projeto:** Em produção / Atualizado

---

## 💻 Tecnologias Utilizadas
Este projeto foi estruturado com tecnologias web nativas e modernas para garantir velocidade extrema de carregamento:
* **HTML5 Semântico:** Estrutura organizada com boas práticas de SEO (`sitemap.xml`, `robots.txt`, tags canonical e Open Graph).
* **CSS3 Moderno:** Estilização avançada com Flexbox, Grid, variáveis personalizadas, efeitos de *glassmorphism* e iluminação neon.
* **JavaScript:** Interatividade de interface e gerenciamento de elementos dinâmicos.
* **Hospedagem & Deploy:** Gerenciamento via GitHub e nuvem.

---

## ✨ Principais Funcionalidades
* **Design Imersivo Dark Mode:** Paleta de cores sofisticada com tons escuros e destaques em azul neon e verde.
* **Componentes Interativos:** Mockup de código simulando ambiente de desenvolvimento e painel de métricas de performance (`2.1s`, `98` score mobile).
* **CTA Estratégicos:** Botões de conversão otimizados e integração direta com contato via WhatsApp (`contato@apexwebdigital.com.br`).
* **Multi-páginas:** Estrutura completa contendo seções de serviços, portfólio de planos, aba "para quem" e formulários de contato.
